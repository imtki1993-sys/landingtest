# Landing Page Motor

MVP d'un générateur de landing pages COD avec workflow GitHub → Vercel.

## Local

\`npm install\`
\`npm run dev\`

## MVP
- Dashboard
- Formulaire produit
- Preview landing page
- Préparation publication GitHub/Vercel

Prochaines étapes: génération IA côté serveur, base de données commandes, authentification et API Vercel.
